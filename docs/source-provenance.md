# Source provenance

Reflect was built by Ibrahim Abdelrahman using Neander. This repository begins with a file snapshot of the delivered application from Neander-managed Git, project `proj_d90eb81fa7be`, commit `1e7864d162e7b3c5f2f7ee55d5a4bc25681f1718`, used by the live delivery reviewed on 21 November 2026.
